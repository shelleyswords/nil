# The NIL Game Plan — Posting Workflow
### How to turn ONE faceless video into 4 platform posts, batch fast, and never run dry

*Built for a one-person operation. Everything is faceless (AI voiceover + visuals), so production is repeatable and batchable. The goal: spend a few focused hours, walk away with 1–2 weeks of content scheduled.*

---

## The core idea: make once, post four times

You make **ONE vertical video** (9:16, AI female voiceover + visuals + on-screen text + captions). That same video goes to **all four platforms the same day** — you just tailor the wrapper (caption, hashtags, link placement) to each.

```
   ONE faceless video (9:16)
            │
   ┌────────┼────────┬──────────────┐
 TikTok   YT Shorts  IG Reels   Facebook Reels
 (native) (native)   (native)    (native)
```

**Do NOT just download from one app and re-upload elsewhere** — apps down-rank videos with another platform's watermark. Always export the clean, watermark-free master file and upload that natively to each app.

---

## Turning ONE video into 4 platform posts

You have a master video + a master caption (from the script package). Here's the per-platform tailoring:

| Platform | Caption length | Hashtags | Link | Tweaks |
|---|---|---|---|---|
| **TikTok** | Short, punchy. Restate the hook + "Free checklist — link in bio." | 3–5 tight tags (#NIL #athletemoney #moneytok + sport/school) | Link goes in the **bio/website field** (say "link in bio") | Add 1–2 trending-but-relevant sounds at low volume under the VO if it fits; reply to early comments. |
| **YouTube Shorts** | A real title matters most. Use the hook as the title + a 1–2 line description. | Add #Shorts + 2–3 topic tags | **Direct link in the description** (YT allows clickable links) | Put the strongest keyword in the title ("NIL taxes," "1% fee"). YT Shorts has search/SEO value. |
| **Instagram Reels** | Hook restatement + light context + CTA. Line breaks for readability. | 5–8 tags, mix broad + niche | Link in **bio** + **link sticker** in a Story re-share | Re-share the Reel to your Story with a "link" sticker pointing to the checklist. Use a strong cover frame. |
| **Facebook Reels** | Slightly more explanatory (older audience / parents). Spell out the value. | 2–4 tags (FB cares less about hashtags) | **Direct link in caption** (FB allows links) | Frame some captions toward parents: "Send this to your athlete." |

**One master, four wrappers.** The video is identical; only the text around it changes.

## The batch workflow (the time-saver)

Batch by **stage**, not by video. Doing the same task 10 times in a row is 5× faster than making one full video start-to-finish, ten times.

**Recommended batch session (half a day = ~2 weeks of content):**

1. **Pick 10 scripts** from `video-scripts.md` (follow the calendar order so pillars stay balanced).
2. **Batch the voiceovers.** Generate all 10 AI voiceovers in one sitting — same female voice, same settings, so the brand sound is consistent. Save them numbered (`vo-21.mp3`, `vo-22.mp3`…).
3. **Batch the visuals.** Go script by script and generate/collect the B-roll + AI images/video from each storyboard. Keep everything in the brand visual system (navy / green / gold, athletic, clean). Save into per-script folders.
4. **Batch the assembly.** In your editor, build all 10 using the SAME template: same fonts, same on-screen-text animation style, same end card, same captions style, same music bed. Drop in VO + visuals per the storyboard.
5. **Batch the export.** Export all 10 as clean 9:16 masters, no watermark.
6. **Batch the captions.** Write all 10 caption sets (they're mostly in the script packages already) — one doc, four columns (TikTok / YT / IG / FB).
7. **Schedule.** Load them into a scheduler (or each app's native scheduler) one per day, at the best post times. Done — two weeks handled.

**Batching tips:**
- **Build ONE master template** in your editor first (intro text style, end card, caption styling, music). Reuse it for every video forever. This is the single biggest time-saver.
- **Keep a consistent music vibe** — one or two royalty-free beds you reuse so the channel "sounds" like itself.
- **Name files by script number** (`21`, `22`…) so calendar → file → caption all line up.
- **Always burn in captions** (on-screen subtitles) — most people watch muted, and it's essential since the VO carries the whole message.
- **Keep a "brand kit" preset**: the hex colors, the fonts, the end card, the logo — saved once, applied always.
- **Aim to stay 1–2 weeks ahead.** Never post your last banked video; that's when quality drops and you scramble.

## Weekly rhythm (lightweight, repeatable)

| When | Task | Time |
|---|---|---|
| **Every other Sunday** | Batch-produce 10 videos (the session above) | ~3–4 hrs |
| **Daily (auto)** | Scheduled post goes out on all 4 platforms | 0 min (scheduled) |
| **Daily (10 min)** | Reply to comments for ~10 min after posting — early engagement teaches the algorithm | 10 min |
| **Weekly (15 min)** | Check analytics: which hook/pillar popped? Note it. | 15 min |
| **Monthly** | Make 2–3 fresh variations of your top performers (new hook, same point) | folded into a batch |

## "What to post when you have nothing" — fallback list

Days happen where you're behind. Reach for one of these — each can be produced fast and stays on-brand:

1. **Re-run a proven winner with a new hook.** Take your best-performing video, rewrite ONLY the first 2 seconds (a new hook line + new opening visual), keep the rest. Totally legitimate — different people see it, and a fresh hook often outperforms the original.
2. **Pull a bonus/backup script.** Scripts 51–52 in `video-scripts.md` are banked exactly for this.
3. **Turn one guide line into a 15-second "one fact" video.** Grab any single sentence from `02-the-nil-playbook-guide.md` (e.g. "An index fund charges around 0.03%"), put it on a navy/gold text card with the AI voice reading it, end card, done.
4. **A "save this" listicle.** Re-cut any 3–5 facts into a numbered screenshot-bait video (like Scripts 27, 34, 41, 48). These are fast and get the highest saves/shares.
5. **Answer a comment as a video.** Screenshot a real question from your comments, put it on screen, answer it in 20 seconds of VO. Free content + it boosts engagement.
6. **A glossary card.** Define one term from the guide's glossary (expense ratio, fiduciary, Roth IRA, 1099) in 15 seconds. Endlessly repeatable.
7. **The "gut check" reel.** Turn one of the guide's 10-second gut checks (Ch. 8) into a quick on-screen-text video.
8. **A myth + the truth.** "Myth: you need a money manager. Truth: you need 4 boring steps." Reuse the format with any myth.
9. **A single jaw-dropping number.** "$400,000." Beat. "That's what a 1% fee can quietly cost you." One number, one reveal, end card.
10. **Repost your pinned video's point** with new visuals. The core ideas (30% to taxes, 1% fee, DM scams) bear repeating — new audiences arrive daily.

**Rule of thumb:** when stuck, the fastest on-brand video is a single fact from the guide on a navy/gold text card with the AI voice + your standard end card. You can make one in under 20 minutes.

## A few guardrails (don't skip)

- **Every video ends with the same end card** (free checklist CTA) — consistency trains the audience to know where to go.
- **Every caption carries** *"Educational only, not financial advice."* Non-negotiable, every post, every platform.
- **One idea per video.** If a script is teaching two things, split it into two videos.
- **Hook in the first 2 seconds or rewrite it.** If a video underperforms, the hook is almost always why — test a new one before abandoning the topic.
- **Never repost watermarked clips** across platforms — always upload the clean master natively.

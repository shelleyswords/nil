## How every script is built (read once)

Every video is **FACELESS**. There is no person on camera. Each video = **one consistent female AI voiceover** (casual-but-professional, trustworthy older-sister/teammate energy) + visuals (B-roll, AI-generated images/video, animated on-screen text, motion graphics) + on-screen text + music.

**Each package contains:**
1. **Title / number**
2. **Pillar** + which guide chapter it covers
3. **HOOK (0–2 sec)** — the first thing said + shown. If this fails, nothing else matters.
4. **VOICEOVER SCRIPT** — the full narration for the female AI voice (~20–40 sec spoken).
5. **SCENE-BY-SCENE STORYBOARD** — each narration beat paired with: ON-SCREEN TEXT + the VISUAL (a specific B-roll keyword OR an AI image/video generation prompt, on-brand).
6. **END CARD** — the standard CTA.
7. **CAPTION + HASHTAGS.**

### The brand visual system (apply to every AI prompt + B-roll choice)
- **Colors:** deep navy (#0B1F3A), athletic green (#1F7A4D), gold accent (#C8A24B), clean white/off-white text.
- **Look:** athletic, clean, modern, premium. Locker rooms, stadiums, turf, sweat, gym light, money/receipts/phone screens, simple animated charts. Cinematic, slightly desaturated, high contrast.
- **Text style:** big bold sans-serif, white or gold, animated in word-by-word; key numbers POP in gold.
- **No faces of real people / no team logos / no real brand names.** Use generic athletic imagery and made-up screen UIs.

### The standard END CARD (use on EVERY video)
> **VISUAL:** Navy background, gold + white text animates in. The NIL Game Plan wordmark bottom-center.
> **ON-SCREEN:** "FREE: The NIL Money Starter Checklist — 7 moves before you spend a dollar. 👉 Link in bio."
